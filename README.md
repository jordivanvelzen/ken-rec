# Ken Rec

A small recorder for kendama practice, by Kendama Senses.

Record a session. When you stop, you see only the last bit, trim it, and the clip is saved to your phone's
gallery (album "Ken Rec"). Nothing is uploaded anywhere.

**Status:** early. Android only, tested on one phone so far.

## Build

```
./gradlew assembleDebug   # the app is app/build/outputs/apk/debug/app-debug.apk
```

Install on a phone with `adb install -r app/build/outputs/apk/debug/app-debug.apk`.
